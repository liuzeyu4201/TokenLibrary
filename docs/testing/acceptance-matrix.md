# 测试策略与验收矩阵

日期：2026-09-26。状态：测试合同；除测试记录明确列出外，以下场景不代表已经执行。

## 层次

- 单元：地址、错误分类、重试、请求冻结、队列确认、Markdown 往返、命名与分词。
- 集成：临时 SQLite、隔离 PostgreSQL、HTTP 替身、文件上传校验、增量应用与备份恢复。
- 构建：macOS 与 iOS Simulator 两目标编译；不等于运行/真机安装通过。
- 端到端：真实 iPhone 与 Mac，测试专用库与附件，完整用户旅程和故障注入。
- 体验：空白库、加载中、空结果、连接失败、过期登录、磁盘失败、冲突、取消、重试与辅助功能。

## 核心矩阵

| ID | 输入/动作 | 必须观察到的结果 | 层次 |
| --- | --- | --- | --- |
| C01 | 空地址、缺协议、错误端口、API 路径 | 发送前给出可修正提示；不上传密码 | 单元/UI |
| C02 | 断网、DNS 失败、连接拒绝、超时、无效 TLS | 不同错误与下一步；本机内容仍可打开 | 单元/真机 |
| C03 | 点击测试连接 | 只 GET health/ready；维护和正常状态分别显示 | HTTP/UI |
| C04 | 登录 401 或返回 HTML/字段缺失 | 不建立伪会话；401 不自动重试；可修改输入重试 | HTTP/UI |
| C05 | 请求 429/503 含 Retry-After | 遵守等待；超过本轮预算交回 UI；无无限重试 | HTTP |
| C06 | 请求期间点击取消或进入本机文档 | 网络和等待停止；迟到响应不能覆盖用户选择 | HTTP/UI |
| S01 | 首次发送提交，响应丢失后重试 | operationId/body/base 完全一致；云端只执行一次 | 单元/集成 |
| S02 | 请求等待期间继续编辑同一文档 | 旧回执只确认旧操作；新内容仍待提交 | 单元/集成 |
| S03 | 失败或强杀重启后继续 | 冻结请求不变；待提交修改仍存在；不自动丢弃 | SQLite/HTTP |
| S04 | 首次空设备同步完整资料库 | 文件夹、正文、PDF、图片、批注、回收站一致 | 两端 |
| S05 | 两端断网改不同段、同一段、同一批注 | 可合并则合并；否则保留冲突和两侧内容 | 两端 |
| S06 | 提交后拉取时继续输入 | 远端快照与旧回执均不覆盖当前输入 | 两端 |
| S07 | 服务器地址/libraryId/epoch 改变 | 旧队列不误发；不静默丢本机草稿 | 集成/两端 |
| F01 | 无权限/无效 UTF-8/损坏 PDF/超大 PDF 导入 | 明确失败；不生成看似成功的空文档 | UI/集成 |
| F02 | MD/PDF 点击导出，取消、保存失败、成功 | 弹出实际文件保存；取消不报成功；失败可重试 | 两端 UI |
| F03 | 导出含图 MD 和带批注 PDF 后外部打开 | 正文/图片/高亮/备注完整，不依赖本机私有路径 | 端到端 |
| E01 | `${...}`、反引号、反斜杠、中文、换行进入 WebView | 作为纯正文传递，不执行插值或丢字符 | 单元/编辑器 |
| E02 | Markdown/表格/任务列表/Mermaid/公式跨端往返 | 源码保真，渲染能力一致，坏语法可修复 | 两端 |
| R01 | 备份失败、超时、重启；到期清理 | 本地可编辑；云端恢复写入；旧备份遵守保留期 | 隔离服务端 |
| R02 | 从真实备份恢复到全新数据库/目录 | PG 可恢复、附件 hash 相同、客户端世代重建正确 | 隔离端到端 |
| L01—L30 | 书籍/论文/专题/摘录/归档 | 按产品文档对应条目逐项验收 | 新方向 |

## 测试样本

至少包含：UTF-8 中英文 Markdown、含特殊字符的代码与公式、50 MB 边界 PDF、有文字层 PDF、扫描 PDF、带批注 PDF、同名文件、同内容不同文件名、已删除/已归档对象。仅以 `%PDF` 开头的短字符串不算真实 PDF 阅读/导出验证。

## 记录格式

每次记录日期、代码状态、环境/工具版本、命令、退出码、通过数量、跳过/失败、证据路径、已知限制。一次故障修复至少有会在旧代码失败的行为回归；不为文案和文档改动机械增加测试。

不得使用真实资料做破坏性恢复/过期清理试验；使用隔离测试库。运行时不得将真实 .env、密码或 Token 写入日志/报告。
