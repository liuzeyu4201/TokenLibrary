# 资料关联与摘录目标选择

## 已修复的问题

2026-09-26 原生验收中，623 项资料使“相关资料 → 选择资料”生成数百行菜单。同名 `page-N` 只有显示标题，无法通过目录区分，也不能搜索。资料详情中的“加入笔记”使用同一种菜单。

`CatalogViews.swift` 现复用 `CatalogDocumentSelectionSheet`：原生可关闭的 sheet 内使用可搜索列表，每行显示标题、文件名、目录、分类与 PDF/Markdown 格式。支持标题、当前/原始文件名、目录、作者和类型匹配，多个空白分隔的词必须同时匹配，不截断为前 500 项。点击整行只选择目标，仍由原表单的保存按钮提交；取消保留原选择及摘录输入。

- 相关资料排除自身、删除项、文件夹，以及任何方向已存在的关联。已归档资料仍可关联和阅读。原有移除关联操作继续调用事务 API，同时处理反向关联。
- 摘录只列出未归档、处于 active 状态的 Markdown，排除当前资料。已经引用来源的笔记仍可追加新的摘录；“新建阅读笔记”保留为独立选项。
- 选择后候选发生删除、归档或关联变动，原表单提示选择失效并禁用提交，不自动切换到另一份笔记。真正保存仍由 Core 检查最新事务状态。
- 缺失目录显示“目录尚未载入”，循环目录显示“目录关系异常”，不会将异常层级伪装为资料库根目录。
- 专题没有成员且没有搜索/筛选条件时，空态说明如何从资料详情加入该专题。搜索无结果与筛选无结果保持原有文案。

## 原生复验步骤

1. 在大于 500 项且有同名文件的库中打开资料详情，选择相关资料；确认可按目录定位、看见文件名和类型、整行可选并可取消。
2. 添加关联后重新打开选择器，确认该资料被排除；在关系另一端移除后，重新打开选择器可再次选择它。
3. 输入摘录，打开笔记选择器，搜索并选择已有笔记；确认取消不丢输入、新建选项仍可用，保存后来源与摘录内容准确。
4. 选择目标后在另一客户端删除或归档目标，刷新本机；确认原选择显示失效。实际保存不能覆盖无效目标，正文输入仍可重新选择后保存。
5. 将专题最后一项移出，确认显示“这个专题还没有资料”，并说明从“整理”勾选专题；全库资料数量不减少。
