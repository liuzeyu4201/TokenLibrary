1. 分别从个人资料库、Markdown、PDF 打开资料详情，改作者或标题，尝试下拉关闭，确认仍在详情且输入保留；点击完成，依次验证继续编辑、明确放弃和保存后离开。
2. 修改书目后打开相关资料或来源，确认同样提示；制造另一设备同字段修改后点保存并继续，确认错误可见、原输入保留且没有导航。
3. 书目未保存时创建摘录，确认摘录成功但打开笔记前仍询问书目；取消后新摘录仍存在。仅有未提交摘录/评论时完成，提示先加入笔记或明确放弃，不静默丢失或隐式创建。
4. 合成混合旧库中放置两个已登记根及一个未知孤儿，确认关系、专题和摘录候选仅显示当前库；同名不同目录仍可区分和搜索。
5. 删除已关联资料或其父文件夹，在另一资料详情移除回收站关系后还原，确认关系不复活；缺失 ID 也可移除。跨设备验此项须先使用含服务端配套修复的隔离服务。
