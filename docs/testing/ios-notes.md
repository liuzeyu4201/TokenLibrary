# iOS 便签与语音验证

更新：2026-09-27。此页记录源码审查、已修复问题、可控后端回归和后续限定的iOS原生便签证据；自动测试不替代真实权限、输入法或音频验收。

## 已修复问题

便签原先在每次输入后保存，再用 `NoteBlockCodec.parse` 重新载入。解析中的 `\s*` 会去掉用户刚输入的末尾空格、换行和媒体说明中的空白，例如 `hello ` 保存后成为 `hello`，继续输入下一词就会连在一起。现有 Markdown 标记格式保持不变；解析只消费编码器添加的单个首尾换行，保留用户的空格、制表符、空行、CR、CRLF、中文和图片/语音说明。旧 CRLF 分隔、旧图片 alt 说明和行内文字标记仍可读取；未识别的媒体标记保留为原始文字，不丢弃内容。

照片选择后的异步读取现在有可取消任务和请求身份；旧任务的完成或 defer 不能清除新选择，离开便签后不再将迟到图片写入附件目录，仍在页面时导入后明确保存。重新出现的便签仅在首次加载或当前草稿干净时刷新，不用远端正文覆盖保存失败的输入。录音的权限请求具有独立身份，取消或离开后的授权回调不能启动隐藏录音，重复点击不会覆盖正在等待的请求；等待时按钮有明确文字。系统权限提示导致的暂时 inactive 不取消请求，进入 background 才收尾。

切到预览、播放另一段语音、进入后台或离开便签，会结束录音并把当前片段加入笔记；系统音频中断与 recorder 完成/错误回调同样结束片段。先保存录音引用，再登记附件；登记失败时原文件仍可从笔记访问并由同步流程重试，不只留一个无入口文件。数据库自身写入失败仍显示保存错误，不能保证磁盘不可写或强制终止时的持久化。

录音、播放和系统中断分别核对请求或会话身份，旧回调不能停止新的录音或清除另一条语音的播放状态。停止、自然播放结束、失败和页面离开会释放音频会话；预览中的停止图标与“停止播放”语义一致，不伪装成可继续的暂停。语音按钮有包含块 ID 的标识，以及操作、时长和短说明组成的可访问标签。

## 另行报告的 iOS 入口缺项

审查时 `TokenLibraryApp.backgroundSync` 在成功同步后没有更新工作区最近成功时间；现已接入与前台相同的持久记录方法。后台任务实际触发和系统时间预算仍需设备验收，不能从代码接通推定后台已运行。

审查时Info.plist缺少 `NSLocalNetworkUsageDescription`，现已补充并在23:55签名更新包核对实际封装。应用允许用户填写局域网服务器，Apple要求本地网络用途说明涵盖直接连接本机网络主机；这一历史缺项不等同本轮已复现网络失败，也不证明真实设备的允许/拒绝分支均已验。[Apple本地网络说明](https://developer.apple.com/documentation/bundleresources/information-property-list/nslocalnetworkusagedescription)

WebKit 图片选择器在当前 iOS 是否提供拍照入口尚未原生确认；如提供，须同时验证摄像头用途说明和拒绝路径，不凭源码将其记为已发生的崩溃。
