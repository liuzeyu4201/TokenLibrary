# 回收还原的原子性与范围

2026-09-26。`DocumentStore.restore` 与服务端选中子树的行为对齐。

- 只恢复选中资料及其同一删除批次、从该资料可达的子孙。单独恢复子文件夹不会恢复父目录、兄弟资料或此前单独删除的资料。
- 原父目录及祖先必须仍是活动普通目录；否则回到同一可信根目录。目录链已丢失时，只有已绑定工作区提供的根身份可作为回退依据，不推测混合旧库的所属根。
- 已到期资料拒绝还原。重复调用已恢复资料不会再次排队。外来根、失效根或不明目录保持原状并返回错误。
- 恢复对象若遇活动同名资料，采用现有 UTF-8 长度限制和不区分大小写的 `_数字` 后缀规则；最终名称和父目录写入同一条 restore 请求。同步重试沿用冻结请求。
- 子树修改与持久队列在一个 SQLite 写事务内提交。队列写入失败，整棵子树回滚。
